# Tag

## Définition
Un `tag` est un texte court qui aide à classer et retrouver une note.

## Données
- `id` : entier
- `label` : entier, max 20 caractères

## Concepts liés
- `note`

## Règle métier
- un tag appartient à aucune, une seul ou plusieurs `note`
